# Pegazka

Apka do nauki dla klas 1–3, na tablet. Pegazka pomaga ćwiczyć:

- **Polski:** brakujące literki, ą/ę/ó/ż i inne, dwuznaki (obrazek + słowo z luką),
- **Matematyka:** dodawanie i odejmowanie do 10, 20 i 100,
- **Angielski:** liczby do 10, kolory i zwierzęta (słowo czytane na głos, wybór obrazka).

Ćwiczenia są losowe. Po każdej odpowiedzi od razu widać ✓ albo ✗, a po rundzie pojawia się
losowa niespodzianka. Apka nic nie zapisuje: bez kont, bez bazy, bez wyników.

## Uruchomienie

To jedna strona (`index.html`) bez instalacji. Wystarczy GitHub Pages:
Settings → Pages → Branch: `main`, folder `/ (root)`.

Na tablecie: otwórz adres strony i wybierz „Dodaj do ekranu głównego”.

## Zmiany

- Nazwa apki i imię maskotki: stałe `NAZWA` i `IMIE` na początku skryptu.
- Nowy temat: dopisz obiekt do listy `TEMATY`.
- Nowe słówko do literek: dopisz je z luką w nawiasie, np. `"k[o]t"`, i dodaj rysunek do `OBR`.
